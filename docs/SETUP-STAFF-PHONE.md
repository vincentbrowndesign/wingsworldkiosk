# Staff phone setup (iPhone, iOS 16.4 or newer)

1. In **Safari**, open `https://<kiosk-domain>/answer.html`.
2. Share → **Add to Home Screen** → Add. Close Safari.
3. Open **WW Kiosk** from the Home Screen (alerts only work from the Home Screen icon).
4. Enter your name and the staff code → **Turn on call alerts** → Allow notifications.
5. Tap **Send me a test alert**. It should arrive in a few seconds.
6. Settings → Notifications → WW Kiosk: Allow, Sounds ON, Time Sensitive if offered. Add WW Kiosk to allowed apps in any Focus you use at work.

Answering: tap the alert → **Answer**. Allow camera/microphone the first time. Uncheck *Show my camera* for voice-only. A manager repeats the same steps on their own phone.

Limits (known): an alert is a notification, not a ringing phone call; it sounds once. If no one answers in 45 seconds the kiosk offers a text-us QR code.
